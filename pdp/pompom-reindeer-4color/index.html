Check Point

이 루돌프의 매력 포인트 3가지
Point 1

폭신폭신
폼폼 몸통

털실을 동글동글 모은 듯한 몸통이라 폭신한 질감이 사진에서도 그대로 느껴져요. 몸통 아래에는 작은 나무 비즈 다리가 달려 있어요.

Point 2

또렷한 얼굴,
빨간 코 포인트

나무 질감의 얼굴에 큼직한 뿔, 빨간 코가 더해져 트리의 초록색 사이에서도 한눈에 들어와요.

Point 3

끈 하나로
바로 걸기

윗부분에 연결된 끈을 트리 가지에 걸어 사용해요.
